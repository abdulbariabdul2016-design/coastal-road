# شركة العلوم التكنولوجية للخدمات والاستشارات الهندسية

نظام إدارة أوراق وحصر أعمال الطريق الساحلي

تطبيق ويب بلغة Python (Flask) لإدارة:
- **الأوراق**: اختبارات، رسائل، وأوراق أخرى (مع إمكانية رفع ملفات PDF / Word / صور أو تسجيل بيانات فقط).
- **حصر الأعمال**: تسجيل الأعمال على طريق ساحلي طوله 100 كم، مقسم إلى جهتين (يمين / يسار).
- **خريطة تفاعلية حقيقية** (بإحداثيات GPS) تعرض مواقع الأعمال باستخدام خرائط OpenStreetMap مجانًا (بدون الحاجة لمفتاح Google Maps).
- **صلاحيات مستخدمين**: أدمن وموظف.

---

## 1. التشغيل على جهازك (محليًا)

### المتطلبات
- Python 3.10 أو أحدث

### خطوات التشغيل

```bash
# 1. الدخول لمجلد المشروع
cd coastal_road_app

# 2. إنشاء بيئة افتراضية (مستحسن)
python3 -m venv venv
source venv/bin/activate      # على ويندوز: venv\Scripts\activate

# 3. تثبيت المكتبات
pip install -r requirements.txt

# 4. إنشاء قاعدة البيانات
flask --app app init-db

# 5. إنشاء أول حساب أدمن (سيطلب منك الاسم واسم المستخدم وكلمة المرور)
flask --app app create-admin

# 6. تشغيل التطبيق
python app.py
```

بعد التشغيل، افتح المتصفح على: `http://127.0.0.1:5000`

سجّل الدخول بحساب الأدمن الذي أنشأته، ثم يمكنك من صفحة "المستخدمون" إضافة بقية الموظفين.

## 1.1 تشغيله كسيرفر Windows والوصول إليه من خارج الشبكة

لتشغيل التطبيق على هذا الكمبيوتر كسيرفر إنتاجي في Windows:

```powershell
cd "C:\Users\user\OneDrive\Desktop\coastal_road_app"
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
flask --app app init-db
waitress-serve --listen=127.0.0.1:5000 app:app
```

للوصول إليه من جهاز آخر عبر الإنترنت بدون أن يكون في نفس الشبكة، ثبّت `cloudflared` من موقع Cloudflare، ثم افتح نافذة PowerShell ثانية وشغّل:

```powershell
cloudflared tunnel --url http://127.0.0.1:5000
```

سيظهر رابط يبدأ بـ `https://` مثل `https://something.trycloudflare.com`. شارك هذا الرابط مع الجهاز الآخر. يجب أن تبقى نافذتا الخادم و`cloudflared` مفتوحتين أثناء الاستخدام.

> هذا الرابط مؤقت ويتغير عند إعادة التشغيل. للحصول على رابط ثابت، أنشئ Cloudflare Tunnel بحساب Cloudflare واربطه بنطاقك. لا تستخدم `SECRET_KEY` الافتراضي عند النشر الفعلي؛ اضبط متغير البيئة `SECRET_KEY` بقيمة عشوائية قوية.

## 2. نشر التطبيق على الإنترنت

التطبيق جاهز للنشر على أي خدمة تدعم Flask + gunicorn. من أسهل الخيارات المجانية/الرخيصة:

### الخيار الأول: Render.com
1. ارفع مجلد المشروع إلى GitHub (بدون مجلد `venv` ولا ملف `app.db` - موجودان في `.gitignore` أصلًا).
2. من Render أنشئ "New Web Service" واربطه بالمستودع.
3. Build Command: `pip install -r requirements.txt`
4. Start Command: تُقرأ تلقائيًا من `Procfile` (`gunicorn app:app --bind 0.0.0.0:$PORT`) — لا حاجة لتعديلها يدويًا.
5. أضف متغيرات البيئة التالية من قسم Environment في Render:
   - `SECRET_KEY`: قيمة عشوائية قوية (مطلوب).
   - `DATABASE_URL`: رابط قاعدة بيانات PostgreSQL (أنشئ واحدة مجانية من Render نفسه: "New PostgreSQL"، أو استخدم Neon). **بدون هذا المتغير ستُستخدم SQLite وستُحذف بياناتها عند كل إعادة تشغيل/نشر على الطبقة المجانية.**
   - `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `ADMIN_FULL_NAME` (اختياري): إذا ضبطتها، سيُنشئ التطبيق حساب أدمن أول تلقائيًا عند أول إقلاع (فقط إذا كانت قاعدة البيانات فارغة من المستخدمين). بعد نجاح أول تسجيل دخول، يمكنك حذف هذه المتغيرات الثلاثة من Render إن أردت.
6. عند أول نشر، يقوم التطبيق تلقائيًا بإنشاء جداول قاعدة البيانات وحساب الأدمن (إن ضبطت متغيراته) دون الحاجة لفتح Shell أو تنفيذ أي أمر يدوي.

### الخيار الثاني: Railway.app
نفس الخطوات تقريبًا، Railway يكتشف `Procfile` تلقائيًا (`web: gunicorn app:app`).

### الخيار الثالث: PythonAnywhere
مناسب إذا كنت تفضل واجهة أبسط وباللغة العربية أدلة كثيرة متوفرة له؛ يدعم Flask مباشرة من لوحة التحكم.

> **ملاحظة مهمة عن التخزين الدائم**: قاعدة البيانات الافتراضية هي SQLite (ملف واحد) والملفات المرفوعة تُخزَّن في مجلد `static/uploads`. بعض خدمات الاستضافة المجانية (مثل الطبقة المجانية في Render) **تحذف الملفات عند كل إعادة تشغيل**. للاستخدام الفعلي والدائم يُفضّل:
> - استخدام قاعدة بيانات PostgreSQL (مدعومة تلقائيًا عبر متغير البيئة `DATABASE_URL`)، أو
> - ربط تخزين دائم (Persistent Disk) لمجلد `static/uploads`.

## 4. ملاحظات حول الخريطة

- الخريطة تستخدم **Leaflet.js** مع طبقة خرائط **OpenStreetMap** المجانية (لا حاجة لمفتاح API ولا اشتراك).
- عند إضافة أو تعديل سجل عمل، تظهر خريطة صغيرة تنقر عليها لتحديد الموقع بدقة (GPS)، وتُحفظ الإحداثيات تلقائيًا.
- صفحة "الخريطة" الرئيسية تعرض كل سجلات الأعمال ذات الإحداثيات، بلون مختلف لكل جهة (يمين / يسار)، مع نافذة معلومات عند النقر على كل نقطة.
- إذا أردت لاحقًا رسم **خط الطريق نفسه** على الخريطة (وليس فقط نقاط الأعمال)، أرسل لي إحداثيات بداية ونهاية الطريق (يمكن الحصول عليها مجانًا من موقع geojson.io) وسأضيفها كخط ثابت على الخريطة.
